# AES_Encryption

A compact AES-128 module that performs manual software encryption and verifies every result against the CPU’s hardware-accelerated AES-NI implementation on x86-64 (Intel/AMD).

## Summary

AES_Encryption is a low-level AES-128 encryption implementation that demonstrates software-based encryption while validating its results against the CPU’s hardware AES-NI implementation. The project is useful for understanding AES encryption at the implementation level and for verifying the correctness of a software implementation against a hardware-accelerated reference.
